# QR Code file transfer

This is a program that transfers files using the camera to scan the QR codes.
It's highly inefficient, and it warms up your phone. So I wouldn't recommend using it for anything except for fun.

## Installation 

Use this command to clone the project:

```bash

git clone github.com/kaloa017/QRCodeTransfer.git

```

Then, you'll need to download the required packages (if you want to run this on a server hosted on the LAN)

```bash

pip install -r requirements.txt

```

After that you simply have to run the server.

```bash

python app.py

```

Then it should be accessible via all devices on the same network via the IP in the terminal.

It also should be noted that this can be accessed on the internet via GitHub Pages here:

https://kaloa017.github.io/QRCodeTransfer/
